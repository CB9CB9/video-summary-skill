# 详细笔记模板

以下是交给 `save` 的 Markdown 正文结构。脚本会补上视频标题、作者、原链接和内容来源。

```markdown
## 概述

用一小段话说明视频讲了什么、主要解决什么问题。

## 分章节笔记

### [时间](视频时间戳链接) 章节主题

- 讲者的主要观点或演示步骤。
- 理解或复现需要的术语、数据、例子与适用条件。

## 核心结论

- 提炼最值得记住的结论或可复用的方法。

## 资料说明

仅在字幕缺漏、语音识别或画面依赖影响理解时，说明哪些内容受到影响。
```

按论述主题组织章节。章节跨越多个字幕分块时，将相关内容归到同一节。明确区分讲者的观点和补充解释。逐字稿缺少可核对的时间戳时，章节标题只写主题。
